# Before a model / map commit

- [ ] Stop Play before accepting edits into the authoring scene.
- [ ] Code changes exist in files; there are no Studio-only script edits.
- [ ] Export accepted Studio models as text .rbxmx into the source tree.
- [ ] Include exported files and placements in the Rojo project.
- [ ] Do not use Terrain or CSG in this milestone.
- [ ] Confirm no embedded third-party scripts or unlicensed materials.
- [ ] Build a fresh place from disk and open it independently.
- [ ] Compare placements, appearance, collision and interactive prompts.
- [ ] Record visual QA and known limits in the test report.

Current map and props are generated from source in World.lua and need no
manual Studio model export. The checklist applies when accepting later edits.
