# Гараж странных находок / Strange Finds Garage

Roblox / Luau. Личный гараж, поиск, доставка и восстановление забытых вещей.

## Текущее состояние

Первый этап реализации v4: четыре предмета, шесть участков, черновая карта,
12 точек появления, ремонт в три действия, продажа, разборка, коллекция,
гарантированное обучение 1–5, RU/EN и сенсорные кнопки.

ProfileStore подключён; Studio использует **Mock**. Прогресс между отдельными
запусками Play в Studio сбрасывается. В опубликованной игре используются
настоящие профили `alpha:<UserId>`. Реальные DataStore требуют проверки
в опубликованном закрытом тесте; успешный Mock её не заменяет.

**Ночь, существо, тележка, багги, способности радио/робота и покупки ещё не
реализованы.** Их параметры подготовлены в Config, но наличие параметров
не означает готовность механик. Сервер Roblox должен быть настроен на 6
игроков при публикации; локальный Config не заменяет настройку Creator Hub.

## Быстрый запуск

1. Открыть `build/StrangeFinds.rbxlx` в Roblox Studio и нажать Play / F5.
2. Гараж назначается автоматически. Перед ним — личный учебный контейнер.
3. Взять контейнер через E или сенсорную подсказку.
4. На бирюзовой площадке гаража сдать груз.
5. Подойти к деревянному верстаку, открыть его, выбрать предмет.
6. Для каждого этапа нажать действие, дождаться таймера, нажать завершение.
7. После выполнения задания нажать кнопку задания на верстаке.

Магазин деталей — красный шкаф справа. Коллекция открывается кнопкой ▦.
Сервер проверяет расстояние: кнопка интерфейса не позволяет работать издалека.

## Разработка

Установить Rokit 1.2.0 из официального выпуска, затем в этой папке:

```powershell
rokit trust rojo-rbx/rojo JohnnyMorganz/StyLua Kampfkarren/selene
rokit install
rojo plugin install
.\scripts\Build.ps1
.\scripts\Build.ps1 -Tests
rojo serve test.project.json --address 127.0.0.1 --port 34872
```

В Studio подключить Rojo к `localhost:34872` в тестовом месте. Код изменять
**только в файлах**. MCP используется для чтения, моделей и проверки игры.

Тестовая сборка содержит TestEZ и случаи в ServerStorage. Обычная сборка
не содержит TestEZ и тестов. В режиме Play / Server запустить:

```lua
return require(game.ServerStorage.GarageTests.Run)()
```

Раннер явно отклоняет пустой запуск, провалы и ошибки TestEZ. Проверки
моделей перед коммитом описаны в `docs/MODEL_CHECKLIST.md`.

## Публикация и данные

- Владелец: личный аккаунт пользователя; одна вселенная для теста и релиза.
- Начальный режим `Config.Environment = "alpha"`; перед релизом — `live`.
- Версия схемы находится внутри профиля, а не в префиксе ключа.
- Не включать Studio Access to API Services для теста над боевыми данными.
- Права на пропуски проверяются по Roblox и не зависят от префикса профиля.
- Сейчас все ID пропусков равны нулю, продажи отключены.
- Перед публикацией заполнить Maturity & Compliance по фактическому контенту.
