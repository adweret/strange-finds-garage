# Гараж странных находок / Strange Finds Garage

Roblox / Luau. Личный гараж, поиск, доставка и восстановление забытых вещей.

## Текущее состояние

Рабочая альфа v4 с черновой картой: десять находок, шесть личных гаражей,
36 точек появления, ремонт в три действия, продажа, разборка, каталог,
учебные предметы, тележка и багги. Есть общий цикл день/ночь, смотритель,
безопасные зоны, радио с шестью тайниками, робот с четырьмя воротами,
заказы после багги, улучшения верстака/склада и оформление.

Интерфейс поддерживает RU/EN, мышь и touch. На телефоне используется
горизонтальная ориентация. Карта, модели и персонаж смотрителя созданы
из собственных Parts. Это основа закрытого теста; баланс, внешний вид и
производительность ещё требуют проверки с игроками.

ProfileStore подключён; Studio использует **Mock**. Прогресс между отдельными
запусками Play в Studio сбрасывается. В опубликованной игре используются
настоящие профили `alpha:<UserId>`. Реальные DataStore требуют проверки
в опубликованном закрытом тесте; успешный Mock её не заменяет.

Сервер Roblox должен быть настроен на шесть игроков при публикации;
локальный Config не заменяет настройку места в Creator Hub. Подготовлен
серверный код пропусков, но все ID равны нулю и продажи отключены.
Реальные покупки и анкета контента не объявляются проверенными.

Отдельное лобби с выбором размера команды и переходом друзей отложено
по пожеланию пользователя. Сейчас вход распределяет Roblox.

## Быстрый запуск

1. Открыть `build/StrangeFinds.rbxlx` в Roblox Studio и нажать Play / F5.
2. Гараж назначается автоматически. Перед ним — личный учебный контейнер.
3. Взять контейнер через E или сенсорную подсказку.
4. На бирюзовой площадке гаража сдать груз.
5. Подойти к деревянному верстаку, открыть его, выбрать предмет.
6. Для каждого этапа нажать действие, дождаться таймера, нажать завершение.
7. После выполнения задания нажать кнопку задания на верстаке.

Магазин деталей — красный шкаф справа. Коллекция открывается кнопкой ▦.
Кнопка ⚙ открывает проекты и темы, а также доступ к верстаку/магазину
при нахождении рядом с ними. ◎ сканирует тайники после установки радио.
Shift / » включает бег; бег и багги создают шум ночью.

Тележка собирается за 450 монет + 4 детали, багги — за 2800 + 12;
для багги нужны инструменты за 250. После таймера проект надо завершить
и вызвать у верстака. Багги управляется WASD или экранными стрелками.
Активный ремонт один; очередь подготовки не увеличивает склад.

Ночная вылазка доступна после продажи лампы: ночью активируй первый
фонарь центральной дороги, дойди до второго и вернись к зоне сдачи.
Она не блокирует остальные задания. Перед рассветом нужно не менее
90 секунд, чтобы начать вылазку. Гаражи и круги света безопасны.

На шаге оборудования гарантированные радио и робот появляются в списке
верстака вне склада; после ремонта они устанавливаются автоматически.
Обычное исправное радио/робота также можно установить отдельной кнопкой.
Сервер проверяет расстояние: кнопка интерфейса не позволяет работать издалека.

## Разработка

Установить Rokit 1.2.0 из официального выпуска, затем в этой папке:

```powershell
rokit trust rojo-rbx/rojo JohnnyMorganz/StyLua Kampfkarren/selene
rokit install
rojo plugin install
.\scripts\Build.ps1
.\scripts\Build.ps1 -Tests
.\scripts\VerifyRelease.ps1
rojo serve test.project.json --address 127.0.0.1 --port 34872
```

В Studio подключить Rojo к `localhost:34872` в тестовом месте. Код изменять
**только в файлах**. MCP используется для чтения, моделей и проверки игры.

Тестовая сборка содержит TestEZ, случаи и Studio-фикстуры в ServerStorage.
Обычная сборка не содержит TestEZ и тестовых модулей; VerifyRelease это
проверяет по составу XML. В режиме Play / Server запустить:

```lua
return require(game.ServerStorage.GarageTests.Run)()
```

Раннер явно отклоняет пустой запуск, провалы и ошибки TestEZ. Проверки
моделей перед коммитом описаны в `docs/MODEL_CHECKLIST.md`.

Для интеграционного сценария шести клиентов открыть тестовую сборку,
выйти из Play и выполнить код `scripts/RunSix.luau` через Command Bar.
Сценарий завершает сеанс сам; его таймаут/исключение/`ok=false` — провал.
Он проверяет отдельные гаражи, чужую/повторную продажу и гонку за находку.
Фикстуры доступны только Studio Mock и отсутствуют в обычной сборке.

Не включать одновременно Rojo и встроенный Script Sync для тех же скриптов.
Rojo здесь управляет всей структурой воспроизводимой сборки. Script Sync
подходит для другого рабочего процесса, где Studio управляет моделями.

## Публикация и данные

- Владелец: личный аккаунт пользователя; одна вселенная для теста и релиза.
- Начальный режим `Config.Environment = "alpha"`; перед релизом — `live`.
- Версия схемы находится внутри профиля, а не в префиксе ключа.
- Не включать Studio Access to API Services для теста над боевыми данными.
- Права на пропуски проверяются по Roblox и не зависят от префикса профиля.
- Сейчас все ID пропусков равны нулю, продажи отключены.
- Перед публикацией заполнить Maturity & Compliance по фактическому контенту.
- Загружать в существующее место `115227968642980` вселенной `10772715396`,
  сохраняя личного владельца и закрытый доступ. Не создавать вторую вселенную.
- Для загрузки использовать чистую `build/StrangeFinds.rbxlx`, а не тестовую.
